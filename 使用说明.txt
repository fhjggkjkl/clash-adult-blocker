HTML 本地网页版使用方法

1. 将完整工具包解压到 Windows 电脑，进入 clash-adult-blocker-web 文件夹。
2. 双击“启动工具.cmd”，也可以双击“start-local.vbs”。
3. 粘贴 Clash / Mihomo 格式的 https 原订阅链接，填好额外屏蔽网站，点击“一键生成手机订阅链接”。
4. 点击“复制订阅链接”。生成的是外网 HTTPS 链接，手机用流量或其他 Wi-Fi 也能导入。
5. 在手机 Clash 新建配置，选择“从 URL 导入”，粘贴链接并下载。
6. 在手机选中生成的配置，开启 VPN 和规则模式。

工具在本地运行，不包含 exe，也无需部署网站。需要 Node.js 22 或更新版本，以及系统自带的 PowerShell 和 OpenSSH 客户端。若缺少 SSH，请在 Windows 可选功能中启用“OpenSSH 客户端”。
外网下载使用 localhost.run 免费通道，规则生成和配置保存都在电脑完成，手机的下载经第三方通道转发；通道提供方处理 HTTPS 解密和下载内容。无需注册或同一 Wi-Fi。
导入、刷新时电脑和工具须保持运行；下载到手机的配置之后可独立使用。免费外网域名可能变化，关闭工具、断网或重连后需重新生成并更新客户端地址，不是永久订阅链接。
只粘贴配置或选择文件时，可先生成配置，再点“导出外网订阅链接”。也保留“导出局域网链接”，这个选项通常需要同一 Wi-Fi。
配置记录保存在 .data/exports，重启后保留。外网地址未变化时，重新导出可更新同一链接；清除浏览器本地数据后可能产生新链接。
流量和到期信息是最近一次读取原订阅时的快照。更新时重新读取、生成并导出，再在手机刷新配置；只导入文件或文本无法获取流量信息。
安装新版后双击启动入口，会识别并停止同一工具的旧服务，再启动新版，保留已保存的本地配置。
不要公开分享 .data 或导出链接，其中包含节点访问凭证。“停用链接”撤回外网和局域网下载，“停止本地服务”同时关闭服务与外网通道。
