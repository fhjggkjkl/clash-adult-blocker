HTML 本地网页版使用方法

1. 将完整工具包解压到 Windows 电脑，进入 clash-adult-blocker-web 文件夹。
2. 双击“启动工具.cmd”，也可以双击“start-local.vbs”。
3. 浏览器会打开 HTML 工具。粘贴 Clash / Mihomo 格式的 https 订阅链接，点击“读取订阅并生成”；也可以直接粘贴完整配置后点击“生成配置”。
4. 点击“导出订阅链接”，再点“复制订阅链接”。
5. 在手机 Clash 新建配置，选择“从 URL 导入”，粘贴链接并下载。
6. 在手机选中生成的配置，开启 VPN 和规则模式。

这是本地网页版，不包含 exe，也无需托管。需要 Windows 自带的 PowerShell 和 Node.js 22 或更新版本。
订阅链接提供的内容就是生成后的完整 YAML，不需要手动传文件。手机导入或刷新订阅时，请保持电脑服务运行，并确保手机能访问链接中的电脑地址。下载完成后，手机运行这份配置无需电脑继续在线。
生成结果保存在本机 .data/exports。重新生成并导出可更新同一个链接，手机刷新订阅即可；清除浏览器本地数据会丢失当前链接的更新记录。
新版会保留原订阅提供方返回的流量和到期信息。升级后停止并重新启动服务，再重新读取原订阅、生成并导出，手机刷新已有链接即可显示。数值是读取时的快照；只导入文件或文本无法获取流量信息。
不要将 .data 文件夹或导出的订阅地址发给别人。可用“停用链接”撤回下载地址，用“停止本地服务”结束服务。
