# Clash Adult Guard

一个在电脑本地运行的 HTML 工具：读取现有 Clash / Mihomo 订阅，加入成人域名拦截规则，一键生成手机用流量或其他 Wi-Fi 也能导入的 HTTPS 订阅链接。适合希望在使用 VPN 时，继续通过原版 Android Chrome 上网的用户。

网页、配置生成与订阅存储都在本机，无需部署网站，不含 exe，不依赖第三方订阅转换网站。外网下载由 localhost.run 通道转发，电脑和工具在导入、更新时需保持运行。双击 Windows 启动入口即可打开网页。详细步骤见 [网页版说明](WEB-TOOL.md)。

## 功能

- 输入订阅链接、粘贴完整 YAML / JSON，或选择配置文件。
- 内置 6,520 条成人域名匹配项，支持补充域名和网址。
- 保留原有节点、DNS 和分流，把拦截规则放在原有规则之前。
- 一键读取、生成配置并导出外网 HTTPS 订阅链接，无需手机和电脑连接同一 Wi-Fi。
- 同时提供局域网 HTTP 链接、Clash 一键导入地址与 YAML 下载。
- 转发原订阅的流量用量、总额和到期信息，供客户端显示。
- 更新同一个导出链接，重启后保留配置，并可随时停用链接。
- 支持 Mihomo / Clash Meta，并提供旧版 Clash 的兼容格式。

本工具将成人域名拦截规则合并进你正在使用的 Clash 配置。**适合 Clash Meta / Mihomo，另提供旧版 Clash 的兼容导出。** 继续使用手机原版 Chrome，无需 root，也无需增加一个 VPN 或改用家庭 DNS。

如果之前设置过导致网络异常的过滤 DNS，请先恢复手机和 Chrome 原来的正常 DNS 设置。

## 读取订阅并导出链接（电脑本地运行，手机 URL 导入）

1. 将完整工具包解压到电脑，安装 [Node.js](https://nodejs.org/) 22 或更新版本。没有额外运行依赖，无需安装 npm 包。
2. 双击“启动工具.cmd”，打开 HTML 本地网页，也可双击“start-local.vbs”。
3. 在输入框粘贴提供方的 Clash / Mihomo 格式 https 订阅链接，设置补充拦截网站后，点击“一键生成手机订阅链接”。请求由电脑直接发给订阅提供方，规则合并在本机完成，不记录原订阅链接。导出后的配置保存在本机 `.data/exports` 中。
4. 复制生成的 HTTPS 链接到手机 Clash 的“从 URL 导入”页面，下载并选中配置，开启 VPN 和规则模式。手机用流量或另一张网络也可导入。

外网链接使用 [localhost.run 的免费通道](https://localhost.run/docs/)，调用系统已有的 OpenSSH 客户端，无需注册或额外 exe。Windows 未启用 OpenSSH 时，需先在系统可选功能中启用“OpenSSH 客户端”。配置在电脑保存，手机的下载会经过通道提供方；该提供方处理 HTTPS 解密和下载内容。仅你明确导出为外网链接的配置可通过通道下载，管理页面和订阅读取接口不会暴露给通道。

**外网链接是临时地址。** [免费域名会变化](https://localhost.run/docs/forever-free/)，关闭工具、电脑断网或通道重连也可能需要重新生成、更新客户端地址。导入和更新时，电脑与工具须保持运行；已下载到手机的配置之后可独立使用。再次导出可更新同一配置记录，当前通道未变化时 URL 不变。工具会检查外网通道连通后再返回链接。

保留“导出局域网链接”作为本地选项：它不使用公网通道，但手机必须能访问电脑的局域网地址，通常需同一 Wi-Fi。也保留 YAML 下载作为备用方式。

完整配置保留原有节点和分流；只有 `proxies` / `proxy-providers` 的节点订阅会补充节点选择组和基础分流，并显示提示。普通编码订阅或节点分享链接需要先在订阅提供方选择 Clash / Mihomo 格式。首次读取需要联网，内置成人名单仍无需联网下载。

直接打开 HTML 文件时，订阅读取和链接导出不可用，请使用上述启动入口。文件导入和配置文本粘贴仍可离线使用。如果未安装 Node.js，可从 [Node.js 官方网站](https://nodejs.org/) 安装，或继续使用下方离线方式。

## 手机或电脑离线导入配置文本

1. 在 Clash 中保留现有配置作为备份，并导出或复制你当前实际使用的完整 YAML 配置。
2. 用 Chrome 打开 `clash-adult-guard.html`。文件导入与粘贴方式可离线使用，不上传配置、不收集浏览记录。如果手机的文件管理器不能用 Chrome 打开 HTML，可以在电脑浏览器完成生成，再把结果传到手机。
3. 在工具内选择现有 YAML 文件，或直接粘贴完整 YAML / JSON 配置，无需选择文件。复制内容带代码块或整个配置被包装成文本字符串时，工具会识别对应格式。订阅读取和链接导出请通过启动入口打开本地网页。
4. 默认选择「Clash Meta / Mihomo」。如确实使用旧版 Clash 内核，选择兼容模式。
5. 有额外要禁用的网站时，可在「补充拦截」中填写域名或网址，每行一个。可留空。
6. 点击「生成配置」，下载生成的 YAML 文件，随后在 Clash 配置页面从本地文件导入，并选中这份新配置。保留原配置，便于撤回。
7. 将 Clash 运行模式设为 **规则模式 / Rule**，启动 VPN。检查 Clash 的应用过滤设置，确保 Chrome 没有被排除在代理/VPN 外。

如果下载按钮在你的手机上不起作用，可以复制生成结果，用本地文本编辑器保存为 `.yaml` 文件。工具不会替你改动手机上的 Clash，需完成第 6、7 步才生效。

如果工具提示某个数值或日期写法有歧义，请先核实原值：端口写成实际的十进制数值，纯数字或日期形式的密码、密钥应使用引号。工具遇到可能改变原值的情况会拒绝生成。

## 流量和到期信息

Clash 的流量显示来自原订阅响应头 `Subscription-Userinfo`，与 YAML 正文分开提供。工具读取原订阅时保留其中的上传、下载、总流量和到期时间，导出的链接在 GET 和 HEAD 请求中都会返回这些信息。

这些数值是最近一次读取原订阅时的快照。重新读取原订阅并导出，再在客户端刷新本地订阅，才会更新用量。工具不统计浏览流量，不自动轮询原订阅，也不会编造剩余额度。原提供方未返回这些信息，或只导入配置文本、文件时，客户端无法显示对应额度。

旧版本升级后，请停止本地服务，重新启动，并重新读取原订阅、生成和导出一次，以便为已有链接补齐流量信息。

## 怎样验证

工具默认加入一条安全测试规则：`guard-check.example.com`。它是保留示例域名下的测试主机，不需要访问真实成人站点。

1. 先在 Chrome 打开平时正常访问的网站，确认网络正常。
2. 在 Chrome 访问 `https://guard-check.example.com/`。
3. **仅看到无法连接不能证明规则生效**，因为这个测试主机本身未必提供服务。请打开 Clash 的连接记录或日志，确认请求被 `REJECT` 拒绝，并命中生成的拦截规则。
4. 如果 Clash 根本没看到这次请求，请检查 VPN 是否启动，以及 Chrome 是否被排除。若没有域名信息，请检查域名识别设置。

某些旧客户端没有完整的拒绝记录显示，可以在连接页检查规则列表是否加载、是否位于其他分流规则前；这仅确认配置加载，不能替代真实拦截验证。

## 工具改了什么

- 把运行模式设为 `rule`。
- 将成人黑名单和补充规则放在原有分流规则之前，命中后使用内核内置的 `REJECT` 策略。
- Meta / Mihomo 模式直接内置域名集合，不需要首次运行时再下载规则文件。
- 旧版 Clash 模式使用 `DOMAIN` 和 `DOMAIN-SUFFIX` 规则，同时保留上游精确域名与后缀匹配的区别。
- Meta / Mihomo 模式提供辅助域名识别选项，用 HTTP/TLS/QUIC 的可见连接信息帮助识别域名。不解密 HTTPS 内容，不安装证书。
- 保留原代理节点、代理组、DNS 和其他配置内容；重新输出 YAML 会改变排版、移除原来的注释、展开部分锚点。请留存原文件。

原订阅更新后，请重新读取、生成并导出，再在手机刷新这个本地订阅链接；工具不会自动轮询原订阅。使用文件导入时，需要重新生成并导入文件。名单是 **2026-10-04** 下载的快照，内置 **6,520** 条域名模式；你可随时补充遗漏域名。

## 撤回和实际范围

在 Clash 中切回你原来那份配置即可撤回本次拦截。

拦截只对 **经过这个 Clash 实例，并且能识别域名的连接** 生效。关闭 VPN、换配置、使用全局代理或全局直连模式、将 Chrome 排除在 VPN 外，都会使这套规则失效。加密客户端问候（ECH）、直连 IP 等情况可能使域名无法识别。

这是域名黑名单，不判断每个网页、视频或图片，不能保证封禁所有成人内容，也没有防关闭密码。若普通网站被误拦，可先切回原配置恢复使用，再修改生成配置中的对应名单条目或补充项。

## 文件与许可

已完成核心离线测试、网页按钮与订阅读取测试、本地链接导出与下载、更新、持久化及停用测试。也已完成 Mihomo 内核配置检查和隔离的本地拦截测试；正常请求可通过，测试黑名单请求被拒绝，没有修改系统代理或启用过滤 DNS。测试使用虚构节点和模拟订阅，尚未连接你的真实订阅或手机实测。

- 启动工具.cmd、start-local.vbs、src/start-web.ps1：Windows 本地网页版启动入口。
- src/web-server.mjs、src/web-service.mjs：本地订阅链接服务。
- src/internet-tunnel.mjs：外网通道与仅提供已发布订阅下载的独立接口。
- src/text-encoding.cjs：字符编码读取组件。
- src/subscription-metadata.cjs：订阅流量信息校验与保留。
- `clash-adult-guard.html`：手机或电脑浏览器可打开的离线配置文本工具。
- src/subscription-server.cjs：HTTPS 订阅读取组件与兼容的旧网页入口。
- `src/`、`build.cjs`：工具源代码及离线构建脚本。
- `tests/`：订阅读取、按钮流程及可选的 Mihomo 内核测试。
- `rules/adult-domains.yaml`：来自 MetaCubeX 的成人域名快照。
- `rules/provenance.md`：具体来源、下载日期、条目数与校验值。
- `rules/LICENSE-MetaCubeX.txt`、`LICENSE.txt`：规则仓库 GNU GPL v3 许可证。
- `vendor/`：固定版本 js-yaml 解析组件及 MIT 许可。单文件工具也内含第三方许可和来源信息。

可在已安装 Node.js 的电脑上运行 `node build.cjs`，无需下载依赖。工具和胶水代码随包以 GPL v3 发布；js-yaml 保留原 MIT 许可。

## 开发

```text
npm run build   # 生成可离线使用的单文件 HTML
npm test        # 核心、订阅读取、网页按钮、流量信息和链接导出测试
npm run verify  # 检查 HTML 打包与内嵌脚本
npm start       # 启动本地网页与订阅服务
```

Windows 用户可直接双击 `启动工具.cmd`。手动启动时，首行输出包含本机工具入口；手机应导入网页生成的订阅链接。可选的真实 Mihomo 内核检查见 `tests/subscription-kernel.cjs` 和 `tests/kernel-routing.cjs`，需要另行提供内核。

运行数据保存在 `.data/`，已经加入 `.gitignore`。不要提交原订阅链接、节点密码、导出配置或访问凭证。

## 项目与上游

本项目负责本地网页、订阅读取、配置合并和订阅链接导出，是基于现有 Clash 生态的应用工具。Clash / Mihomo 内核、成人域名名单和 YAML 解析器来自各自上游项目；完整来源、快照校验值和许可随项目保留。它不是 Chrome 扩展，也不需要在手机 Chrome 中安装插件。
