给浏览器加一道拦截

粘贴现有订阅或配置，加入成人网站拦截，再导出订阅链接到手机 Clash。Chrome 照常使用。

本地生成配置手机流量也能导入保留原有节点与分流
此工具生成客户端配置文件。手机需要已安装支持 Clash / Mihomo 配置的客户端，并开启 VPN 或 TUN，让 Chrome 流量经过客户端。名单可能有遗漏或误判，不能保证拦住所有成人内容。

1导入现有配置

双击「启动工具.cmd」打开本地网页版，支持读取订阅和导出订阅链接。

直接粘贴订阅链接或完整 YAML / JSON 配置，不需要选择文件。订阅读取和链接导出请通过「启动工具.cmd」打开本地网页版。生成后会重新排版 YAML，原注释不保留。

2选择拦截设置

Mihomo 格式使用内嵌名单；旧版格式展开为普通域名规则。

会同时拦截该域名及其子域名。中文域名也支持。

3导出订阅链接

外网链接可用手机流量或其他 Wi-Fi 导入，通过第三方通道转发下载，电脑和工具须保持运行。免费地址可能变化，变化后请重新生成并更新客户端地址。配置在本机保存，通道提供方会处理下载内容。

链接包含配置的访问凭证，请妥善保管。重新生成后再次导出，会更新这个链接的内容。

查看配置或下载 YAML
  1. 在手机客户端新建配置，选择「从 URL 导入」，粘贴上方订阅链接，下载后选中配置并启用规则模式。
  2. 打开客户端 VPN / TUN，确认 Chrome 流量经过客户端。
  3. 在 Chrome 打开 https://guard-check.example.com，再在客户端连接日志中确认命中 REJECT。该地址本身可能打不开，仅凭打不开不能判断拦截成功。

原订阅节点更新后，请重新读取、生成并导出，在手机中更新这个订阅。关闭客户端或换用其他配置会使拦截失效。
